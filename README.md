## What it does

ERplorer indexes your codebase and test results, then lets anyone search them by pasting an error message. It returns the exact file, line number, and surrounding code — no IDE, no clone, no local setup.

Built for QA teams. Runs entirely in the browser. Zero cost, zero servers.

## Quick start

1. Open [ERplorer](https://suryasticsai.github.io/erplorer/)
2. Paste an error message
3. Read the file:line result
