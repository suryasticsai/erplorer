What makes ERplorer unique
Five features no other QA tool ships out of the box.
🧬 Error DNA
Normalizes error text (strips UUIDs, numbers, timestamps) and clusters similar errors. See "×47" instead of scrolling 47 near-identical results.
💥 Blast Radius
For any error, extracts identifier names and shows every other file in the index that references them. Instant impact analysis, zero config.
🔧 Fix Recipe
Pattern-matched suggested fixes for the most common JavaScript, Java, Python, and SQL errors. Not AI guesswork — curated rules.
📋 Copy Bug Report
One click turns any result into a formatted Markdown bug report — file:line, context, repro hint. Paste into Jira, Linear, or Slack.
🔗 Share Link
Every search is URL-encoded. Copy the link, send it to a teammate, and they see the exact same results with one click.

How to use ERplorer

A quick walkthrough of every tab.

1Search — find where an error lives▶
  • Paste an error message, a stack trace line, or a SQL keyword into the search box.
  • Results show the file, line number, and surrounding 5 lines of code.
  • Error DNA — the pink "×N" badge clusters similar errors.
  • Blast Radius — shows other files referencing the same identifier.
  • Fix Recipe — inline suggested fix for common errors.
  • Copy Bug Report — one-click markdown to clipboard.
  • Share Link — copy a URL that reopens this search.
2Ask — chat with the index▶

Ask questions in plain English. The tool finds matching entries locally, then sends only those to the AI for a briefing. If AI is unavailable, matched entries are shown as chat cards — the tool always works.

3Lab — turn test cases into code▶

Scenarios: describe steps, convert with AI or rules. Specs: drop an Excel/CSV, get Playwright and pytest files.

4Ingest — grow the searchable index▶

Four ways: fetch a URL, scan a GitHub repo, drop files, or paste text. Everything stays in your browser.

About me
I've been a QA engineer, a full stack developer, a Java backend dev, and a Scrum Master. In every one of those roles, I watched teams lose hours to the same problem: an error message in a CI log that nobody could locate in the codebase.

ERplorer is my answer. Paste an error, get the file and line. No IDE, no clone, no context switch. Built entirely in vanilla JavaScript so it runs from any browser, on any machine, for any team — no install, no build, no cost.
