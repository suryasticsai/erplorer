How to use ERplorer

A quick walkthrough of every tab. Each panel is self-contained — use what you need, ignore the rest.

1 Search — find where an error lives ▶

The fastest way to locate any error in the codebase.

  • Paste an error message, a stack trace line, or a SQL keyword into the search box.
  • Results show the file, line number, and the surrounding 5 lines of code.
  • The matched text is highlighted in amber inside the code block.
  • Use the filter chips (All / Errors / Java / Python / SQL / Config / Tests) to narrow by type.
  • Press Enter to save a query to your recent history.
2 Ask — natural language over the index ▶

Ask questions in plain English instead of guessing keywords.

  • Type something like "Which file has the login validation errors?"
  • ERplorer finds the top matching entries locally, then sends only those to the AI.
  • Answers come with clickable [1] [2] citations.
  • If AI is unavailable, matches are shown as a chat-style list — the tool always works.
3 Lab — turn test cases into code ▶

Two ways in: write scenarios in English, or drop a spreadsheet.

  • Scenarios: describe test steps. Convert with AI or rules. Edit the table, then generate specs.
  • Specs: drop an Excel/CSV with test rows. Get Playwright and pytest files.
4 Ingest — grow the searchable index ▶

Four ways: fetch a URL, scan a GitHub repo, drop files, or paste text. Everything stays in your browser.

5 Rules — teach ERplorer your team's errors ▶

Add regex patterns for error formats specific to your codebase. Applied automatically on the next crawl, scan, or paste.

6 Settings — theme, token, and local data ▶

Toggle dark mode via the sun/moon icon in the header. Configure GitHub token for private repo scanning. Reset local data to clear all history and patterns.

About me
I've been a QA engineer, a full stack developer, a Java backend dev, and a Scrum Master. In every one of those roles, I watched teams lose hours to the same problem: an error message in a CI log that nobody could locate in the codebase.

ERplorer is my answer. Paste an error, get the file and line. No IDE, no clone, no context switch. Built entirely in vanilla JavaScript so it runs from any browser, on any machine, for any team — no install, no build, no cost.
